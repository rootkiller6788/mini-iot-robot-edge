# 功能安全标准参考文档

## 1. IEC 61508 功能安全概述

### 1.1 标准框架

IEC 61508 是功能安全的基础标准，适用于所有电气/电子/可编程电子 (E/E/PE) 安全相关系统。

```
IEC 61508-1:  一般要求
IEC 61508-2:  E/E/PE 系统要求
IEC 61508-3:  软件要求
IEC 61508-4:  定义和缩略语
IEC 61508-5:  SIL 确定方法
IEC 61508-6:  IEC 61508-2/3 应用指南
IEC 61508-7:  技术和措施概述
```

### 1.2 安全生命周期

```
概念 → 范围定义 → 危害和风险分析 → 安全要求 → 安全系统设计
                                              ↓
退役 ← 修改 ← 运行和维护 ← 验证 ← 安装调试 ← 实现
```

### 1.3 SIL 等级详解

SIL (Safety Integrity Level) 等级定义:

**低要求模式 (low demand mode):**
- 要求频率 ≤ 1次/年
- 度量: PFDavg (平均失效概率)

| SIL | PFDavg | 风险降低因子 (RRF) |
|-----|--------|-------------------|
| 1 | ≥10⁻² to <10⁻¹ | >10 to ≤100 |
| 2 | ≥10⁻³ to <10⁻² | >100 to ≤1000 |
| 3 | ≥10⁻⁴ to <10⁻³ | >1000 to ≤10000 |
| 4 | ≥10⁻⁵ to <10⁻⁴ | >10000 to ≤100000 |

**高要求/连续模式 (high demand / continuous mode):**
- 要求频率 > 1次/年
- 度量: PFH (每小时危险失效概率)

| SIL | PFH (per hour) |
|-----|----------------|
| 1 | ≥10⁻⁶ to <10⁻⁵ |
| 2 | ≥10⁻⁷ to <10⁻⁶ |
| 3 | ≥10⁻⁸ to <10⁻⁷ |
| 4 | ≥10⁻⁹ to <10⁻⁸ |

### 1.4 PFDavg 计算

**1oo1 架构 (单通道):**
```
PFDavg = λDU × TI / 2

其中:
  λDU = 未检测到的危险失效率
  TI  = 检验测试间隔 (proof test interval)

示例: λDU = 1×10⁻⁶/hour, TI = 8760h (1年)
  PFDavg = 1×10⁻⁶ × 8760 / 2 = 4.38×10⁻³ → SIL2
```

**1oo2 架构 (双通道, 任一通道即可执行安全功能):**
```
PFDavg = λDU × TI × β (共因失效部分忽略)

如果考虑共因失效:
PFDavg_1oo2 ≈ (λDU × TI)² / 3 + β × λDU × TI / 2

其中 β = 共因失效因子 (common cause failure factor)
典型 β 值: 1%-10%
```

**2oo3 架构 (三取二):**
```
PFDavg_2oo3 ≈ 2 × (λDU × TI)² + β × λDU × TI / 2
```

### 1.5 硬件故障裕度 (HFT)

| SIL | 最小 HFT (Type A) | 最小 HFT (Type B) |
|-----|-------------------|-------------------|
| 1 | 0 | 0 (SFF≥60%) |
| 2 | 1 (SFF≥60%) | 1 (SFF≥90%) |
| 3 | 2 (SFF≥60%) | 1 (SFF≥99%) |

**Type A**: 所有故障模式已知且可完全确定 (继电器、电阻等)
**Type B**: 故障模式不完全知晓 (微处理器、ASIC等)

## 2. ISO 13849-1 机械安全

### 2.1 PL (Performance Level) 等级

ISO 13849-1 定义 PL (性能等级) a-e:

| PL | PFHd (每小时) | 对应 SIL |
|----|---------------|---------|
| a | ≥10⁻⁵ to <10⁻⁴ | 无对应 |
| b | ≥3×10⁻⁶ to <10⁻⁵ | SIL1 |
| c | ≥10⁻⁶ to <3×10⁻⁶ | SIL1 |
| d | ≥10⁻⁷ to <10⁻⁶ | SIL2 |
| e | ≥10⁻⁸ to <10⁻⁷ | SIL3 |

### 2.2 类别 (Categories)

| 类别 (Cat.) | 要求 | 最大可达 PL |
|-------------|------|------------|
| B | 基本安全原则 | a-b |
| 1 | 经验证的元件和原则 | a-c |
| 2 | 周期性测试 | a-d |
| 3 | 单一故障不导致安全功能丧失 | a-e |
| 4 | 多重故障不导致安全功能丧失 | e |

### 2.3 PL 确定参数

```
PL = f(MTTFd, DCavg, Cat., CCF)

MTTFd:  每个通道的平均危险失效时间 (Mean Time To Dangerous Failure)
DCavg:  平均诊断覆盖率 (Diagnostic Coverage, average)
CCF:    共因失效 (Common Cause Failure)
```

**MTTFd 分级:**
| 级别 | MTTFd (年) |
|------|-----------|
| 低 (Low) | 3 ≤ MTTFd < 10 |
| 中 (Medium) | 10 ≤ MTTFd < 30 |
| 高 (High) | 30 ≤ MTTFd ≤ 100 |

**DCavg 分级:**
| 级别 | DCavg |
|------|-------|
| 无 (None) | < 60% |
| 低 (Low) | 60% ≤ DCavg < 90% |
| 中 (Medium) | 90% ≤ DCavg < 99% |
| 高 (High) | ≥ 99% |

## 3. 安全功能设计指南

### 3.1 紧急停止 (E-Stop)

**设计要求 (ISO 13850):**
- 类别 0 (立即断电) 或 类别 1 (受控停止后断电)
- 红色蘑菇头按钮，黄色背景
- 至少双通道 (Cat.3/PLd 或以上)
- 手动复位 (不能自动重启)
- 拉出或旋转释放 (不能简单按下)

**双通道 E-Stop 电路:**
```
+24V ──→ [E-Stop NC contact 1] ──→ [Safety Relay Ch.A]
+24V ──→ [E-Stop NC contact 2] ──→ [Safety Relay Ch.B]
                                    ↓
                            [Main Contactor Coil]
                                    ↓
                            [Motor Power OFF]
```

**差异检查时间:**
- 机械触点: 10-50ms (通常)
- 推荐设置: 100ms
- 太短: 误触发 (触点弹跳)
- 太长: 安全功能延迟

### 3.2 安全门联锁

**设计原则:**
1. 门打开 → 危险运动停止
2. 门关闭 ≠ 自动启动 (需单独启动命令)
3. 联锁装置需达到 PLd (SIL2) 或以上
4. 防止 defeat (通过工具固定开关)

**互锁类型:**
| 类型 | 说明 | 适用 PL |
|------|------|---------|
| 机械式 | 物理阻止门打开 | up to PLe |
| 非接触式 (磁) | 干簧管/霍尔传感器 | up to PLc |
| RFID 编码 | 编码唯一，防欺瞒 | up to PLe |
| 锁定式 | 门可锁定 (guard locking) | up to PLe |

### 3.3 安全光幕

**分辨率与安全距离:**
```
S = K × T + C

S = 最小安全距离 (mm)
K = 人体接近速度 (mm/s), 一般 2000mm/s
T = 总停止时间 (s)
C = 附加距离 (mm)

对于手指保护 (14mm 分辨率):
  C = 0

对于手保护 (30mm 分辨率):
  C = 8 × (d - 14), d = 分辨率 (mm)

示例: 手指保护, 停止时间 100ms
  S = 2000 × 0.1 + 0 = 200mm
```

**检测区域:**
```
┌─────────────────────────────────────┐
│      光幕发射器                      │
│       │ │ │ │ │ │ │ │ │ │ (光束)     │
│       ↓ ↓ ↓ ↓ ↓ ↓ ↓ ↓ ↓ ↓           │
│      光幕接收器                      │
└─────────────────────────────────────┘
       ← 保护区域宽度 →
           ← 安全距离 S →
                    ┌────────┐
                    │ 危险区  │
                    └────────┘
```

### 3.4 双手控制

**ISO 13851 (EN 574) 要求:**

**类型 III (要求最高):**
- 同时按下两按钮
- 释放任一按钮 → 停止
- 两按钮需在 0.5s 内同时按下
- 两按钮距离 ≥ 260mm (防止单手操作)
- 防意外操作 (护罩/凹陷安装)
- 达到 Cat.4 / PLe

**配置:**
```
    ┌────┐                           ┌────┐
    │BtnL│ (左按钮)                  │BtnR│ (右按钮)
    └──┬─┘                           └──┬─┘
       │                                │
       └────────────┬───────────────────┘
                    ↓
          ┌─────────────────┐
          │ Two-Hand Logic   │
          │ (Safety PLC)     │
          └────────┬─────────┘
                   ↓
          ┌─────────────────┐
          │ Safe Output      │
          │ (Dual Contactor) │
          └────────┬─────────┘
                   ↓
          ┌─────────────────┐
          │ Machine Run      │
          └─────────────────┘
```

**时间窗口验证:**
```
时间线:
t=0   : 左按钮按下 → 启动 500ms 定时器
t=300 : 右按钮按下 → 在窗口内 → 输出 ON
t=0   : 左按钮按下 → 启动 500ms 定时器
t=600 : 右按钮按下 → 超时 → 输出保持 OFF
t=任意: 释放一按钮 → 输出 OFF
```

### 3.5 安全转矩关断 (STO)

**IEC 61800-5-2:**
STO 是变频器最基础的安全功能。

| 特性 | 说明 |
|------|------|
| 功能 | 防止电机产生转矩 |
| 实现 | 切断驱动信号的电源 |
| 安全状态 | 电机自由旋转或制动 |
| SIL等级 | 通常 up to SIL3 |
| 响应时间 | < 10ms (典型) |

**与标准停机的区别:**
```
标准停机: CPU 控制 PWM 关闭 → 可能仍有余电
STO:      硬件切断 IGBT 门极驱动 → 绝对无转矩
```

## 4. 安全通讯协议对比

### 4.1 PROFIsafe vs CIP Safety

| 特性 | PROFIsafe | CIP Safety |
|------|-----------|------------|
| 基本协议 | PROFINET/PROFIBUS | EtherNet/IP |
| 组织 | PI (PROFIBUS & PROFINET Intl.) | ODVA |
| 最大 SIL | SIL3 (IEC 61508) | SIL3 (IEC 61508) |
| 报文长度 | 12-123 bytes | 可变 |
| CRC | CRC24 (0x864CFB) | CRC (SCM) |
| 序列号 | 24-bit | Time Coordinated |
| 看门狗 | 可配置 | 可配置 |
| 黑色通道 | 是 | 是 |
| 安全数据 | ≤ 12 bytes/prod. | 可配置 |

### 4.2 "黑色通道" 原理

安全通讯协议通过"黑色通道" (Black Channel) 传输：

```
┌──────────────────────────────────────┐
│         安全数据 (Safety PDU)         │
│  ┌─────────────────────────────────┐ │
│  │ 用户数据 + CRC + SN + etc       │ │
│  └───────────────┬─────────────────┘ │
│                  ↓                    │
│  ┌─────────────────────────────────┐ │
│  │    标准协议栈 (黑色通道)         │ │
│  │    TCP/UDP/Industrial Ether     │ │
│  └─────────────────────────────────┘ │
└──────────────────────────────────────┘
```

黑色通道不提供安全保证，所有安全措施在安全层实现。这使得安全通讯可以在任何标准网络上传输。

### 4.3 残余错误率计算

```
PROFIsafe 残余错误率 (SIL3):

安全措施组合:
  Consecutive Numbering: λ_err1 = 10⁻⁷
  Timeout:               λ_err2 = 10⁻⁹
  Codename:              λ_err3 = 10⁻⁸
  CRC:                   λ_err4 = 10⁻¹⁰
  Addressing:            λ_err5 = 10⁻⁷

总残余错误率:
  λ = λ_err1 + λ_err2 + λ_err3 + λ_err4 + λ_err5
    = 10⁻⁷ + 10⁻⁹ + 10⁻⁸ + 10⁻¹⁰ + 10⁻⁷
    ≈ 2.011 × 10⁻⁷  (< 10⁻⁷ per hour? No: 2×10⁻⁷ > 10⁻⁷)

注意: 对于 SIL3, PFH < 10⁻⁷/h 是针对整个安全功能的。
PROFIsafe 层贡献的残余错误 < 1% 的 SIL3 预算。
```

## 5. 安全验证与确认

### 5.1 检验测试 (Proof Test)

检验测试是定期执行以检测未发现危险故障的测试。

**典型检验测试:**
```
E-Stop 系统:
  1. 按下 E-Stop → 预期: 主接触器断开
  2. 测量断开时间
  3. 复位 E-Stop
  4. 按启动按钮 → 预期: 系统正常启动
  5. 记录测试结果

典型间隔: 每 6-12 个月
```

### 5.2 安全文档要求

IEC 61508 要求的功能安全管理文档:

1. **安全计划** - 安全活动计划和管理策略
2. **危害与风险分析** (H&RA) - 识别危险源和 SIL 确定
3. **安全要求规范** (SRS) - 安全功能和安全完整性规格
4. **安全验证计划** - 验证方法、标准和通过/失败条件
5. **验证报告** - 各生命周期阶段的验证结果
6. **功能安全评估** (FSA) - 独立安全评估报告
7. **操作维护手册** - 检验测试、维护程序、故障响应
